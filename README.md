# HR Analytics & Employee Attrition Dashboard | Power BI

## Project Overview

This project is an interactive Human Resources (HR) Analytics Dashboard developed using Microsoft Power BI.

The dashboard explores employee information, workforce distribution, salary categories, job satisfaction, and employee attrition patterns.

The aim is to transform HR data into meaningful visual insights that can help organisations understand workforce trends, monitor employee retention, and support data-driven human resource decisions.

## Project Objectives

The primary objectives of this project are to:

- Analyse employee demographics and workforce distribution.
- Examine employee attrition across different departments.
- Explore attrition patterns across gender and age groups.
- Analyse employee distribution across salary categories.
- Examine job satisfaction across different job roles.
- Explore the relationship between employee experience and attrition.
- Present HR information through interactive Power BI visualisations.

## Dashboard Overview

The dashboard contains several visualisations and KPI cards.

### 1. Key Performance Indicators (KPIs)

The dashboard includes five KPI cards:

- **Employee ID Count:** Displays the count of employee IDs.
- **Employee Count:** Shows the employee count measure.
- **Attrition Count:** Displays the attrition count measure.
- **Average Age:** Shows the average employee age.
- **Average Years at Company:** Displays the average number of years employees have spent at the company.

### 2. Attrition by Department

A donut chart visualises attrition across different departments.

This allows users to examine how employee attrition is distributed across organisational departments.

### 3. Employee Distribution by Salary Slab

A clustered bar chart examines employee counts across salary slabs, with attrition included as a breakdown.

This provides a way to explore workforce distribution across different salary categories.

### 4. Job Role and Job Satisfaction

A table visual presents:

- Job Role
- Attrition Count
- Job Satisfaction

This enables comparisons of attrition and job satisfaction across different roles.

### 5. Employee Count by Age Group

A column chart displays employee distribution across different age groups.

This helps explore the demographic composition of the workforce.

### 6. Attrition by Gender

A pie chart visualises attrition by gender, allowing users to compare the distribution across gender categories.

### 7. Attrition and Total Experience

An area chart presents attrition count alongside total experience in years.

This provides an additional perspective for exploring employee experience and attrition patterns.

### 8. Interactive Filtering

The dashboard includes an age-group slicer that allows users to filter the report by age category.

## Business Questions

The dashboard is designed to investigate the following HR questions:

1. How many employees are represented in the dataset?
2. How is employee attrition distributed across departments?
3. How does attrition vary across gender categories?
4. How are employees distributed across different age groups?
5. How does employee distribution vary across salary slabs?
6. Which job roles have different levels of attrition?
7. How does job satisfaction vary across job roles?
8. How can employee experience be explored alongside attrition?
